Hi All -

The main questionnaire refactoring has been completed. This is a very extensive rewrite, modernizing the questionnaire structure into a fully class based plugin. This allows for automated testing to cover almost all functionality.

Additionally, a number of security concerns have been dealt with. Full details can be found at [Github](https://github.com/PoetOS/moodle-mod_questionnaire/releases#release-v5.3.1) and at [Moodle Marketplace](https://marketplace.moodle.com/plugins/mod_questionnaire/versions).
